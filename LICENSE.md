# License

**No license has been granted. All rights are reserved.**

This is a statement of the current position rather than a license, and it is
written down because silence on this question is worse than an unwelcome answer.
Somebody deciding whether to build on this software needs to know now, not after
they have.

## What that means for you

**You may install PathLMS and run it**, on your own infrastructure, for your own
organization, including commercially.

**You may not** fork it, redistribute it, republish the container images, or
build and distribute something derived from it. Nobody has been given permission
to do those things, so nobody has it.

## Where this is going

The intention is to release PathLMS as open source. Which license, and when, has
not been decided.

Until it is decided, this page says so plainly rather than implying a permission
that has not been granted.

## If that is a problem

It reasonably might be. An organization that needs software it can fork, audit
under an open license, or carry on maintaining if the project stops has a real
requirement that this does not meet today.

If that is you, **Moodle, Canvas and Open edX** are all mature, well supported and
genuinely open, and choosing one of them is the right call rather than a
consolation. This page would rather tell you before you install than after.

## The software this is built on

PathLMS stands on a large amount of open source work, all of it under its own
license and none of it changed by anything on this page. The components are named
in the [README](README.md), and their licenses are their own.
